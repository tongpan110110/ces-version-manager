# 版本对比页 PRD

---

## 一、页面定位

版本对比页用于**对比两个版本的组件和需求差异**，帮助版本经理、测试、SRE 了解版本升级带来的变化。

---

## 二、核心设计原则

1. **聚焦差异**：只展示有变化的内容
2. **SOP 友好**：组件差异可直接用于编写升级 SOP
3. **信息完整**：同时展示组件变更和需求/缺陷变更

---

## 四、模块说明

### 4.1 头部

- **标题**：版本对比
- **副标题**：对比两个版本的组件和需求差异

---

### 4.2 版本选择器

| 元素 | 说明 |
|-----|------|
| 版本 A | 下拉框，选择基准版本 |
| 版本 B | 下拉框，选择目标版本 |
| 开始对比 | 按钮，点击后执行对比 |

- **下拉框内容**：所有版本计划，显示版本号和类型
- **按钮状态**：两个版本都选择后才可点击

---

### 4.3 组件差异

对比两个版本的组件版本变化。

#### 表格列

| 列名 | 说明 |
|-----|------|
| 组件名称 | 组件标识 |
| 版本 A | 基准版本中的组件版本，无则显示 `-` |
| 版本 B | 目标版本中的组件版本，无则显示 `-` |
| 变更 | 升级 / 不变 / 新增 / 下线 |

#### 变更类型判断

| 变更类型 | 条件 |
|---------|------|
| 升级 | 版本 A < 版本 B |
| 不变 | 版本 A = 版本 B |
| 新增 | 版本 A 无，版本 B 有 |
| 下线 | 版本 A 有，版本 B 无 |

#### 组件顺序

1. 前端组件（CES-Portal）
2. 后端组件（按名称排序）

#### 导出按钮

导出组件差异为 Excel/CSV 格式。

---

### 4.4 新增内容

展示版本 B 比版本 A 新增的需求和缺陷。

#### 表格列

| 列名 | 说明 |
|-----|------|
| 单号 | 需求或缺陷编号 |
| 描述 | 需求或缺陷的描述 |
| 类型 | [需求] 或 [缺陷] |

#### 数据来源

- **新增需求**：版本 B 的关联需求中，版本 A 没有的
- **新增缺陷**：版本 B 的关联缺陷中，版本 A 没有的

#### 排序

按单号排序。

---

## 五、交互说明

### 5.1 点击行为

| 元素 | 点击行为 |
|-----|---------|
| 版本下拉框 | 选择版本 |
| 开始对比 | 执行对比，显示结果 |
| 导出按钮 | 导出组件差异 |

### 5.2 空状态

- **组件差异为空**：显示"两个版本的组件完全相同"
- **新增内容为空**：显示"无新增需求或缺陷"

---

## 六、数据来源

| 数据 | 来源 |
|-----|------|
| 版本列表 | Plan 表 |
| 组件信息 | Manifest 表 + ManifestComponent 表 |
| 关联需求 | Plan.relatedRequirements |
| 关联缺陷 | Plan.relatedBugs |

---

## 七、与现有设计的差异

| 原设计 | 新设计 | 原因 |
|-------|-------|------|
| 对比版本类型、状态、描述等元信息 | 对比组件版本 | 组件差异才是核心价值 |
| 无需求/缺陷对比 | 新增需求/缺陷对比 | 了解版本带来的功能和修复 |
| 表格有"状态"和"详细信息"列 | 简化为四列 | 更简洁 |
| 需求和缺陷分开显示 | 合并为一个表格 | 更紧凑，用类型列区分 |
