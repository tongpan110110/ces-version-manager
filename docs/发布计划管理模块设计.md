# 发布计划管理模块设计

## 界面设计

```
┌─────────────────────────────────────────────────────────────────────────┐
│  发布计划管理                                          [导入] [导出]     │
│  ───────────────────────────────────────────────────────────────────────│
│  ┌────────┬────────┬────────┬────────┬────────────────────┬────────┐  │
│  │ 版本号 │ 版本线 │ 类型   │ 状态   │ 摘要               │ 操作   │  │
│  ├────────┼────────┼────────┼────────┼────────────────────┼────────┤  │
│  │ 25.8.2 │ 25.8   │ 需求版 │ 升级中 │ 新增客户管理...   │ [详情] │  │
│  │ 25.8.1 │ 25.8   │ 需求版 │ 已完成 │ 性能优化           │ [详情] │  │
│  │ 25.8.2.1│ 25.8   │ 补丁版 │ 测试中 │ 修复任务中心...   │ [详情] │  │
│  └────────┴────────┴────────┴────────┴────────────────────┴────────┘  │
│                                                        [+ 添加发布计划] │
└─────────────────────────────────────────────────────────────────────────┘
```

---

## 数据结构

```typescript
interface Plan {
  version: string           // 版本号，如 25.8.2
  versionLine: string       // 版本线，如 25.8
  type: "Release" | "Patch" // 类型
  status: "draft" | "testing" | "released" | "upgrading" | "completed"
  summary: string           // 摘要
  relatedRequirements: string[]  // 关联需求
  relatedBugs: string[]     // 关联缺陷
  manifest?: {
    frontendVersion: string
    frontendChangeType: string
    components: {
      componentName: string
      targetVersion: string
      changeType: string
      changeReason: string
    }[]
  }
}
```

---

## 状态映射

| 数据库值 | 显示 |
|---------|------|
| draft | 开发中 |
| testing | 测试中 |
| released | 研发出包 |
| upgrading | 升级中 |
| completed | 已完成 |

## JSON 格式

```json
{
  "plans": [
    {
      "version": "25.8.2",
      "versionLine": "25.8",
      "type": "Release",
      "status": "upgrading",
      "summary": "新增客户管理功能、工单优化",
      "relatedRequirements": ["REQ-001", "REQ-002"],
      "relatedBugs": ["BUG-001"],
      "manifest": {
        "frontendVersion": "2.8.2",
        "frontendChangeType": "upgrade",
        "components": [
          {
            "componentName": "CES-Portal",
            "targetVersion": "2.8.2",
            "changeType": "upgrade",
            "changeReason": "功能更新"
          },
          {
            "componentName": "ces-gateway",

            "changeType": "upgrade",

    }

```

---

## 功能说明

| 功能 | 说明 |
|-----|------|
| **导入** | 导入发布计划 JSON 数据 |
| **导出** | 导出当前所有发布计划 |
| **详情** | 点击展开显示该版本的组件信息 |
| **添加** | 手动添加新的发布计划 |

---

## 位置

放在"组件管理"和"全量数据管理"之间，保持模块顺序一致性。
