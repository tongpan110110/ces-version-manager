# 系统设置页 PRD

---

## 一、页面定位

系统设置页用于**配置和管理系统基础数据**，支持可视化配置和 JSON 导入导出两种方式。

---

## 二、核心设计原则

1. **简单实用**：先满足初始化数据导入的需求
2. **两种方式**：可视化配置 + JSON 导入，灵活选择

---

## 四、模块说明

### 4.1 版本线配置

#### 可视化配置

| 列名 | 说明 |
|-----|------|
| 版本线 | 如 25.8.x, 25.10.x |
| 目标版本 | 该版本线的目标版本 |
| 状态 | 启用/禁用 |
| 操作 | 编辑/删除 |

#### JSON 格式

```json
{
  "versionLines": [
    {
      "versionLine": "25.8",
      "baseline": "25.8.2",
      "active": true
    },
    {
      "versionLine": "25.10",
      "baseline": "25.10.0",
      "active": true
    }
  ]
}
```

---

### 4.2 局点管理

#### 可视化配置

| 列名 | 说明 |
|-----|------|
| 局点 | 局点名称，如北京、上海 |
| 区域 | 国内/亚太/中东/非洲/拉美 |
| 当前版本 | 该局点当前运行的版本 |
| 后端 | ● 已升级 / ○ 待升级 |
| 前端 | ● 已升级 / ○ 待升级 |
| 操作 | 编辑/删除 |

#### JSON 格式

```json
{
  "regions": [
    {
      "name": "北京",
      "area": "domestic",
      "version": "25.8.2",
      "backendReady": true,
      "frontendReady": true
    },
    {
      "name": "上海",
      "area": "domestic",
      "version": "25.8.2",
      "backendReady": true,
      "frontendReady": false
    }
  ]
}
```

---

### 4.3 组件管理

#### 可视化配置

| 列名 | 说明 |
|-----|------|
| 组件名称 | 组件标识 |
| 说明 | 组件用途描述 |
| 操作 | 编辑/删除 |

#### JSON 格式

```json
{
  "components": [
    {
      "name": "CES-Portal",
      "description": "前端",
      "type": "frontend"
    },
    {
      "name": "ces-gateway",
      "description": "网关服务",
      "type": "backend"
    },
    {
      "name": "ces-auth",
      "description": "认证服务",
      "type": "backend"
    }
  ]
}
```

---

### 4.4 全量数据管理

#### 导出全部数据

导出包含所有数据的 JSON 文件，包括：
- 版本线配置
- 局点数据
- 组件数据
- 发布计划

#### 导入全部数据

导入全量 JSON 文件，**覆盖模式**：
- 清空现有数据
- 导入新数据

**注意**：此操作会覆盖所有数据，慎用。

---

## 五、交互说明

### 5.1 导入操作

| 步骤 | 操作 |
|-----|------|
| 1 | 点击「导入」按钮 |
| 2 | 选择 JSON 文件 |
| 3 | 系统校验格式 |
| 4 | 校验通过，执行导入 |
| 5 | 显示导入结果 |

### 5.2 导出操作

| 步骤 | 操作 |
|-----|------|
| 1 | 点击「导出」按钮 |
| 2 | 系统生成 JSON 文件 |
| 3 | 浏览器下载文件 |

---

## 六、数据来源

| 数据 | 存储位置 |
|-----|---------|
| 版本线配置 | SystemConfig 表 |
| 局点数据 | Region 表 + RegionVersion 表 |
| 组件数据 | ManifestComponent 表（可作为配置维护） |
| 发布计划 | Plan 表 |

---

## 七、导入模式

| 模块 | 导入模式 |
|-----|---------|
| 版本线 | 合并式（保留现有，添加新的） |
| 局点 | 覆盖式（清空现有，重新导入） |
| 组件 | 覆盖式（清空现有，重新导入） |
| 全量数据 | 覆盖式（清空所有，重新导入） |
