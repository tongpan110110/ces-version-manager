# 发布计划列表页 PRD

---

## 一、页面定位

发布计划列表页是**版本计划的管理入口**，提供所有版本计划的查看、筛选和新建功能。

---

## 二、核心设计原则

1. **筛选高效**：一行筛选区，快速定位目标版本
2. **信息简洁**：卡片只展示关键信息，详情点击进入
3. **URL 可分享**：筛选条件体现在 URL，支持从仪表盘跳转带参数

---

## 四、模块说明

### 4.1 头部

- **标题**：发布计划
- **新建计划按钮**：点击打开新建弹窗

---

### 4.2 筛选区

一行四个筛选条件：

| 筛选项 | 类型 | 选项 |
|-------|------|------|
| 搜索框 | 输入框 | 搜索版本号或描述 |
| 版本线 | 下拉框 | 全部版本线 / 25.8.x / 25.10.x / ...（动态） |
| 状态 | 下拉框 | 全部状态 / 开发中 / 测试中 / 研发出包 / 升级中 / 已完成 |
| 类型 | 下拉框 | 全部类型 / 需求版 / 补丁版 |

- **筛选逻辑**：实时生效，无需点击按钮
- **URL 参数**：筛选条件同步到 URL，支持分享和跳转
  - 示例：`/plans?versionLine=25.8&status=testing&type=Patch`

---

### 4.3 计划列表

#### 卡片内容

| 元素 | 说明 |
|-----|------|
| 版本号 | 大字体突出显示 |
| 类型标签 | [需求版] 或 [补丁版] |
| 状态标签 | [开发中] / [测试中] / [研发出包] / [升级中] / [已完成] |
| 版本摘要 | 简要描述 |
| 箭头 | 点击进入详情 |

#### 排序规则

**按创建时间倒序**：最新创建的版本排在最前面

#### 空状态

当筛选结果为空时显示：
```
暂无符合条件的发布计划
[清除筛选条件]
```

点击「清除筛选条件」重置所有筛选项。

---

### 4.4 新建计划弹窗

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| 版本号 | 输入框 | 是 | 如 25.8.3 或 25.10.0.1 |
| 类型 | 下拉框 | 是 | 需求版 / 补丁版 |
| 版本摘要 | 文本框 | 是 | 描述版本主要内容 |
| 关联需求 | 输入框 | 否 | 逗号分隔，如 REQ-001, REQ-002 |
| 关联缺陷 | 输入框 | 否 | 逗号分隔，如 BUG-001, BUG-002 |

- **版本线自动提取**：从版本号自动提取，如 25.8.3 → 25.8
- **初始状态**：创建后状态为「开发中」
- **创建成功后**：跳转到详情页

---

## 五、版本状态定义

| 数据库状态 | 页面显示 | 说明 |
|-----------|---------|------|
| draft | 开发中 | 研发正在开发 |
| testing | 测试中 | 测试正在验证 |
| released | 研发出包 | 测试通过，研发已出包，等待升级 |
| upgrading | 升级中 | 正在全网推广 |
| completed | 已完成 | 全网升级完成 |

---

## 六、交互说明

### 6.1 点击行为

| 元素 | 点击行为 |
|-----|---------|
| 新建计划按钮 | 打开新建弹窗 |
| 计划卡片 | 跳转到详情页 `/plans/{planId}` |
| 清除筛选条件 | 重置所有筛选项为默认值 |

### 6.2 URL 参数

支持从其他页面跳转时带筛选参数：

| 参数 | 说明 | 示例 |
|-----|------|------|
| versionLine | 版本线 | `25.8` |
| status | 状态 | `testing` |
| type | 类型 | `Patch` |
| search | 搜索关键词 | `客户管理` |

示例：从仪表盘「查看全部补丁」跳转
```
/plans?versionLine=25.8&type=Patch
```

## 八、与现有设计的差异

| 原设计 | 新设计 | 原因 |
|-------|-------|------|
| 状态：草稿/待测试/待发布/已发布/已废弃 | 开发中/测试中/研发出包/升级中/已完成 | 与 PRD 统一 |
| 无版本线筛选 | 添加版本线下拉框 | 支持多版本线筛选 |
| 卡片显示版本线标签 | 删除 | 版本号已能体现版本线 |
| 卡片显示覆盖局点 | 删除 | 无业务价值 |
| 卡片显示更新时间 | 删除 | 无业务价值 |
| 有筛选按钮 | 删除 | 筛选实时生效，不需要按钮 |
| 无排序规则 | 按创建时间倒序 | 最新创建的在前面 |
| 空状态只显示文字 | 添加清除筛选按钮 | 更友好 |
| URL 不支持参数 | 支持筛选参数 | 可从仪表盘跳转带参数 |
